# Johnny Semaan — website

Static site, no build step. Served from this folder by GitHub Pages.

## Sequence
Liquid-pigment name/fish intro (2.6 s) → identity hold (3 s) → sketch surfacing, black graphite on paper with a black frame (3.7 s) → hold (0.65 s) → menu.
Reduced motion skips straight to the menu. Returning home never replays the opening.

## Tunables
- `opening.js` → `LIGHT_SOFTNESS` — intro light strength (1 = original study, 0.55 current).
- `site.css` → `--sketch-paper`, `--sketch-frame`, `--sketch-frame-ink`.
- `content.json` — paintings and exhibitions shown on the two pages.

## Provenance
Derived from `trials/gallery-v06-working-site` (Codex, Oct 2026) in the parent project.
Identity marks, handwritten lettering and artwork files are unchanged from that version.
